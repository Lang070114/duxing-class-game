## 规则说明

- 游戏有故事线：百歌回声道具 → 校园补给 → 大二更新 → 个人时间取舍 → 班级超能 → 未来设施。
- 无正确答案、个人排名、失败路线。时间币代表两个优先方向，不代表每天只剩两小时。
- 所有计时仅提醒；主持人可以按15分钟预算推进，绝不自动关题、跳关或生成报告。
- 选择和投票分布实时同步，剧情和彩蛋、地图点亮在揭晓时展示。开放文字无需审核。
- 并列：例如10、5、5、0票，第一名保留，第二名两个候选都保留；时间剧情只展示第一名分别搭配两个第二名，不出现遗漏第一名的组合。四项全并列保留六种可能组合。
- 美食仅规范化空白、大小写、全半角和标点，合并相同店名＋菜品；不猜测不同别名是否同一商家。
- 主观题不设逐题字数上限。长回答在卡片内滚动，可在报告与导出中完整读取；百歌为五轨动态弹幕，点击可看全文；其他文字事件大屏每9秒换一组，不会推进关卡。服务器1MiB单次请求保护不等于逐题字数要求。
- 未投票或只有一个设施有票时，如实保留空缺，不编造第二名。
- 房间创建后保留7天，首次生成报告后重新保留7天；到期清理规则保留。秘密和答题数据不进入GitHub或升级ZIP。

## 本地启动

要求 Node.js 24，项目依赖已安装。

```powershell
node scripts/build-standalone.mjs
node --disable-warning=ExperimentalWarning standalone-dist/server.mjs
```

本机打开 http://127.0.0.1:3020/?view=host ，主持口令在 standalone-dist/data/host-key.txt。沿用已有数据目录会保留主持口令。已有房间沿用旧规则；新建房间才是六事件版。

## 班委快速测试与多人测试

1. 新建时勾选演示模式。进入第一关，点开始收集，再加入本关演示数据。可反复点，不重复计数。
2. 依次结束收集、揭晓、下一关、开始收集；演示页面/导出始终标记模拟数据。
3. 正式多人联测另建不勾选演示的房间。电脑开主持和投影页，至少两部手机以不同浏览器加入，验证手机提交、修改、状态票、双选和最终设施投票。
4. 局域网测试需用电脑实际Wi-Fi地址生成二维码，手机与电脑同网且设备可互访。云端部署后不要求同网。
5. 临时切断某部手机网络，再恢复：确认已保存内容保留、未提交草稿可再次提交、关题后提交被拒绝。主持重置后旧草稿不得提交到新轮次。
6. 保存私密入口、报告及CSV/JSON。重置只用于测试，点击前先导出。

## 腾讯云升级

公网当前仍是旧版。新版交付包为 duxing-game-v0.3.0.zip，包内没有口令、数据库或测试答案。

1. 在原腾讯云文件管理器上传ZIP到 /root。
2. 执行：

```bash
unzip -n /root/duxing-game-v0.3.0.zip -d /root/duxing-update-v0.3.0
bash /root/duxing-update-v0.3.0/update-tencent.sh
```

脚本适配此前对话配置：游戏 /opt/duxing-game/portable-game，数据 /var/lib/duxing-game，服务 duxing-game。它先停服一致性备份代码、数据库、口令及Nginx配置，再升级并迁移；保留原systemd运行用户和Node路径。失败自动恢复，备份只留在服务器，权限700。开放题请求大小同步从16k调整为1m。不会购买资源、改变安全组或替换主持口令。

成功后浏览器强制刷新，创建新的演示房间测试。旧房间继续旧流程，避免误读之前的答案。正式班会另建正式房间，更新PPT二维码。

需要手动回退时先导出新版答案，再在原终端执行（把备份目录换为升级输出的实际目录）：

```bash
BACKUP=/opt/duxing-backups/实际备份目录
[ -f "$BACKUP/app/server.mjs" ] && [ -f "$BACKUP/data/answers.sqlite" ] || exit 1
systemctl stop duxing-game
cp -a "$BACKUP/app/." /opt/duxing-game/portable-game/
mv /var/lib/duxing-game "$BACKUP/data-after-upgrade-$(date +%s)"
mkdir -p /var/lib/duxing-game
cp -a "$BACKUP/data/." /var/lib/duxing-game/
chown -R duxing-game:duxing-game /var/lib/duxing-game
chmod 700 /var/lib/duxing-game
cp -a "$BACKUP/nginx.conf" /etc/nginx/conf.d/duxing-game.conf
nginx -t
systemctl start duxing-game
systemctl reload nginx
```

回退会恢复升级前的数据快照；新版期间的数据留在备份目录，不会自动转换给旧版。
