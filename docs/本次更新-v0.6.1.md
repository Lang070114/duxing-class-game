# v0.6.1：一人可以发送多条弹幕

百歌、外卖推荐、大二感受的文字改为每次发送新增一条，旧内容继续保留。发送成功清空输入区，手机页面显示“我发过的内容”；刷新后可以恢复记录。每一条可单独审核或隐藏。

大二状态投票仍为每人一票，以最后提交的状态为准；发送多条文字不会增加票数。时间币和电影单选规则沿用原版本，电影片名仍是选填、先审核。收集结束后不能再发弹幕。

同一条发送遇到网络重试时只保存一次；主动再次发送使用新的发送标识。相同内容可以主动再发，但同一个人重复推荐同一店菜、重复提及同一个词，都不会被算成多个人。词云仍保留每一条原话的来源。

## 腾讯云升级

将 `duxing-game-v0.6.1.zip` 上传到服务器 `/root`，在腾讯云黑色终端执行：

```bash
unzip -n /root/duxing-game-v0.6.1.zip -d /root/duxing-update-v0.6.1
bash /root/duxing-update-v0.6.1/update-tencent.sh
```

出现“升级完成：游戏 v0.6.1”后，电脑 Ctrl+F5，手机关闭旧页重新进入。主持网址、口令、原房间与参与凭证保留；本次多条弹幕功能可以在已有的新版房间使用。原先六关房间仍保持六关题义，若想改用电影终关，需要新建五关房间。

脚本在升级前备份程序、数据库与Nginx配置，检查失败会恢复。数据库增加消息表，并将已有的前三关文字及隐藏状态复制进消息表，不删除原答案。升级前已经被旧版覆盖的更早文字无法凭空恢复。

## 本地测试

需要Node.js 24，在项目目录运行：

```powershell
npm run build:standalone
npm run start:standalone
```

打开启动窗口提供的主持入口，使用对应环境的主持口令。用同学端在百歌题连续发送两条，再刷新检查“我发过的内容”。第二关可以连续发不同店菜；第三关连续发感受并更新状态，揭晓后应当仍然只有每位参与者的一票。

JSON完整备份新增 `messages` 字段保存逐条文字，`answers` 字段保留每人每题的投票／最近提交记录。CSV中弹幕逐条导出，状态投票单列，不把同一文字在两类记录中重复导出。报告与PNG包含全部已公开弹幕，隐藏文字不进入公开报告。
