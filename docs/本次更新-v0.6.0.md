# v0.6.0：我们班的大学第二季

本次修改在本地项目完成，腾讯云需要上传并执行升级包后生效。正式使用请继续收藏腾讯云原主持网址；不要把 localhost 当作手机公网入口。

## 内容与兼容
新建房间为五关：百歌回忆、东校园生存指南、大二感受、24小时时间币、我们班的大学第二季。原第5关搭子和第6关彩蛋合并为电影单选。旧房间保留旧题义、原始答案和权限，不会自动变更为新题。升级后必须新建房间测试新终关。

六种电影类型使用需求原文，必须单选。片名选填、多行、无逐题字数上限；投票和文本分别存为 choice 与 text。开放期间可更新，一人始终只计一票。

电影关仅显示总提交人数；分布在结束收集后仍隐藏，主持人点击揭晓才公布。其他关卡保留之前的隐藏规则。最高票并列全部保留；无人参与不指定类型、不填充票数。片名全部先待审核，主持端展开“主持管理”逐条“审核通过并展示”；即使提前审核，也要揭晓后才进入大屏。修改已通过片名会重新待审，投票仍有效。投影请使用独立投影页，不要投影主持审核面板。

报告与PNG导出仅含已揭晓票数和已审核片名，保留原文；不再出现新房间的搭子或班建任务。结尾衔接院领导讲话。上一关、重开、重置、口令、房间备份和部署方式保持。

## 本地验收
需要 Node.js 24。项目目录运行：

    npm run build:standalone
    npm run start:standalone

用启动窗口提供的主持网址和私密说明中的本地口令，新建演示房间。可逐关加入明确标识的演示数据，或用手机加入同一局域网的地址。五关顺序推进均由主持人决定，计时不自动跳转。请在电影关测试：只选类型提交；补填多行片名；主持审核；关闭收集；揭晓；上一关与重开；生成报告、导出PNG、进入老师寄语。

独立测试预览使用3048端口；本地口令与腾讯云口令是两个独立环境，腾讯云升级不会修改原口令。

## 腾讯云升级
上传 duxing-game-v0.6.0.zip 到 /root，依次执行：

    unzip -n /root/duxing-game-v0.6.0.zip -d /root/duxing-update-v0.6.0
    bash /root/duxing-update-v0.6.0/update-tencent.sh

脚本会先停服务并备份程序、数据与Nginx配置，再升级；失败自动回滚。保持原云端host-key、数据库、端口和网址。成功后浏览器 Ctrl+F5，新建房间，再保存新的私密主持链接及参与二维码。包内不含数据库、口令或房间私密入口。

## 离线
offline.html 已同步五关。完全断网时由主持人录入真实举手统计和经过确认的口头片名，不接收手机答案，不补写数据。应急版与云端互相独立。
