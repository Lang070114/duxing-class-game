# 笃行班游戏 v0.4.0：本次修改与升级

继续使用原来的腾讯云主持入口：http://43.139.189.171/?view=host 。主持口令、房间码、参与二维码和已保存的答案都不更换。本次在原项目上修改，没有替换技术栈或数据库。

## 四项修改

1. 东校外卖：准备/开放/暂停时用动态弹幕显示“店名 · 菜品”；点击结束收集后立即切换推荐卡片墙；同店同菜继续合并，主持可隐藏或恢复。
2. 大二更新日志：删除“这条更新属于”的分类选择，只填写最大变化并选当前状态。收集中显示弹幕；结束收集后仍保留弹幕，点击揭晓结果才显示关键词云。状态分布保留。
3. 上一关：每个事件都有返回选项，第一关可返回集合。返回会停止当前题收集并保留全部答案；回到的题默认展示已有结果。需要补充时点重新开放收集。再点下一关也不会清空原答案或重复计数。报告也可回到第六关。
4. 六种剧情：使用用户截图中的名称和文案，剧情揭晓、最终报告、断网报告保持一致：

| 组合 | 结局 |
|---|---|
| 学业＋探索 | 超级进取模式：学业进度和未来探索同步推进！不过，系统检测到你的日历正在发出红色预警。 |
| 学业＋同行 | 并肩作战模式：学习和友谊并不矛盾，也许一起学习、互相支持，比独自硬扛更有效率。 |
| 学业＋续航 | 稳定输出模式：你选择先把重要的事情做好，也为自己保留恢复精力的时间。 |
| 探索＋同行 | 组队探索模式：新的兴趣与发展机会，有时就是从一次同学间的交流开始的。 |
| 探索＋续航 | 可持续探索模式：你愿意尝试新的方向，也意识到不能一直依靠透支精力前进。 |
| 同行＋续航 | 生活体验模式：大学不仅有成绩与履历，也有友情、兴趣和照顾自己的时间。 |

并列继续保留相应候选组合，不随机裁决，不设失败路线。第一关的同频回声道具彩蛋保留。所有计时仅提醒，仍由主持人手动推进。

## 词云如何形成

从本场未隐藏的更新日志自动分词，去除常见虚词，每条回答选取至多六个关键词；相同词在同一份答案里只记一次，大小代表提及该词的回答人数。中文分词优先使用浏览器内置Intl.Segmenter，不支持时使用本地词表与文本分段降级，不调用外部AI或上传到第三方服务。

点击词语可查看对应匿名原话，展开“词频与逐条关键词来源”可核对完整依据；隐藏回答立即从词云中排除。最多60个关键词参与图形排布，完整词频和原话保留在展开区。没有可提取内容时如实显示为空。

## 升级腾讯云（只做一次）

1. 下载 duxing-game-v0.4.0.zip，上传到腾讯云文件管理器的 /root。
2. 在原黑色终端执行：

```bash
unzip -n /root/duxing-game-v0.4.0.zip -d /root/duxing-update-v0.4.0
bash /root/duxing-update-v0.4.0/update-tencent.sh
```

脚本先停服备份代码、数据库、口令和Nginx配置，再更新。失败自动恢复；备份目录在终端显示。没有数据库结构变更，已有v0.3.0六事件房间刷新即可继续，不需要重新创建、不更换口令或参与二维码。旧v0.2.0房间仍保留原五任务玩法。

3. 看到“升级完成：游戏 v0.4.0”后，电脑打开原主持网页并按 Ctrl+F5；手机端关闭旧页后从原二维码重新进入，避免旧页面缓存。
4. 确认外卖“开始收集”为弹幕、“结束收集”为卡片；更新日志揭晓为词云；上一关返回后人数和答案保留。
