# 独立多人版本与腾讯云部署准备

## 当前状态

Sites已返回发布成功，但用户手机和本机网络无法正常访问其域名，不能当作正式班会入口。独立版本已准备，不依赖Sites或Cloudflare数据库运行。

## 免费局域网玩法

电脑已安装Node.js 24。构建 `node scripts/build-standalone.mjs`，运行 `node standalone-dist/server.mjs`，或解压交付ZIP后双击启动文件。

电脑和手机必须在同一教室Wi-Fi，网络须允许设备互相访问。主持人通过启动窗口提供的教室网络地址打开主持入口，二维码才会指向正确的教室网络。电脑保持开机、服务保持运行。程序不修改防火墙；由使用者决定是否允许专用网络的入站连接。Wi-Fi有设备隔离时此方式不可用。

本地SQLite数据库保存在 `standalone-dist/data`。关闭再启动仍保留答案，运行时清理到期数据；程序关闭时不执行后台清理。把备份和答题导出保存在自己电脑，不提交GitHub。

## 腾讯云部署准备

独立版本可部署到支持Node.js 24且具有持久磁盘的服务器，例如腾讯云轻量应用服务器。已提供Dockerfile。此路径需要用户本人登录腾讯云账户并完成必要的账号认证，先核实免费试用资格、地域、费用和公网入口，再开通资源。不能保证每个账户都能免费领取，不自动购买或开启付费续费。

使用容器时必须挂载持久目录：

```sh
docker build -t duxing-game .
docker run -d --name duxing-game --restart unless-stopped -p 80:80 -v duxing-data:/data duxing-game
```

生成的主持口令位于持久目录的 `host-key.txt`。也可以通过服务端环境变量 `HOST_SETUP_KEY` 设置长随机口令。不要将口令写进镜像、源码或公开地址。

本地SQLite版本应只运行一个实例。不要部署到会丢弃本地文件的无状态云函数，或在多个实例间各自使用独立SQLite文件。公网域名、HTTPS、微信访问和平台约束需在账号及部署地域确认后核验；不能用测试域名的临时成功替代正式入口验证。
