# 笃行班班会与六事件主持流程（v0.5.0）

## 45分钟班会

| 环节 | 预算 |
|---|---:|
| 班长开场 | 3分钟 |
| 团支书介绍 | 4分钟 |
| 文娱委员与百歌回顾 | 5分钟 |
| 互动游戏 | 15分钟 |
| 院领导讲话 | 15分钟 |
| 转场与机动 | 3分钟 |

百歌介绍结束，班长接：“刚才我们回看了一起登台的样子。接下来，用十五分钟看看：走进大二，我们班还能怎样一起联机。”

## 游戏15分钟预算

所有时间为主持参考，系统不自动关题或跳关。开放题选读两条，不逐条念完；超时优先缩短点评。

| 游戏内时间 | 事件 | 现场动作 |
|---|---|---|
| 0:00—1:00 | 集合 | 展示参与二维码，强调匿名、无个人排名 |
| 1:00—2:30 | 百歌通关弹幕 | 开始收集，读两条；结束、揭晓，获得同频回声 |
| 2:30—4:00 | 东校园生存指南 | 店名＋菜品，收集时弹幕，结束后推荐卡片墙；读两份补给 |
| 4:00—6:00 | 大二更新日志 | 先选状态、留言选填；收集时不显示票数，揭晓后看词云与状态分布 |
| 6:00—9:00 | 24小时不够用 | 四方向选二，各一枚币；揭晓六分支中的实际组合与道具彩蛋 |
| 9:00—11:00 | 寻找班级搭子 | 自愿多选搭子类型，留言选填，揭晓后看分布，不现场配对 |
| 11:00—13:00 | 解锁未来班级 | 四彩蛋选二；揭晓点亮得票较高候选，并列保留，另议可行性与时间 |
| 13:00—15:00 | 通关与领导转场 | 看报告、保存结果，进入院领导寄语页面 |

可点击上一关返回查看；所有答案保留，未揭晓的题返回后仍不显示统计，补交请重新开放；再次向前进入会重新隐藏结果，等待揭晓。

每关操作：进入本关 → 开始收集 → 结束收集 → 揭晓结果 → 下一关。暂停/恢复用于现场停顿；重新开放用于补交；参考计时加30秒不会自动跳转。

## 逐关串词

1. “如果用一句话评价我们班的百歌之旅，你会说什么？这些回声会成为我们后面的一件道具。”
2. “舞台通关之后，还要解决今天吃什么。向队友推荐一家东校园外卖，写清店名和菜品。”
3. “到大二了，最近过得怎么样？先选个状态就行，愿意多说一句也可以。”
4. “时间不能无限加，但优先级可以自己选。把两枚时间币投向两个方向。没有正确答案，看看我们班会走进哪一种剧情。”
5. “有些事情有人一起做就方便多了。你想找哪类搭子？只看匿名分布，不现场配对，之后愿意的人自己联系。”
6. “这里有四个可能的小计划，选两个你想进一步了解的。今天只留候选，会后再确认能不能做、谁负责、什么时候做。”

时间剧情反转：“队友发来消息：最近有点忙不过来，能一起想想办法吗？第一关那些不同的声音能合成一首歌，现在不同的优先级，也能成为彼此的补位。”

报告收尾：“这份报告里，有共同经历，也有正在面对的选择。游戏结束，但我们的故事还在继续。接下来，有请院领导结合这些真实的声音，为进入大二的笃行班送上建议与寄语。”

## 一人主持安排

主持控制页留在电脑，独立投影页放大屏；投影页没有控制按钮与主持口令。第一关前扫码完成即可，无需全程展示二维码。先保存私密入口，换电脑时从该文件恢复。

普通回答直接展示；明显隐私和攻击性文字先暂存，主持在私密管理区确认后再展示。其他不适合展示的文字可事后隐藏。主观题无逐题字数上限，卡片可滚动；主持只读简短代表内容。所有真实回答仍可导出，报告公开部分排除已隐藏内容。

并列只陈述实际票数，不宣布系统选出了唯一优胜者。设施表示共同候选，不等于当场承诺全部建成。

## 断网切换

提前下载“笃行班-断网应急版-v0.5.0.html”。个别手机掉线先等待自动重连，未确认的提交重新提交；全场网络故障时主持打开离线文件，改用自愿口头分享和举手，由主持录入实际结果。离线数据与云端数据分开，不重复混算。

结束后保存报告PNG（长报告为分页PNG的ZIP）、HTML/PDF，导出CSV/JSON。正式房间不要添加演示数据；演示房间有醒目标记，仅用于测试。

## 无人或少人参与

0—10秒说明题目和操作，10—20秒自然观察，20秒后可点“显示备用讲解”，30秒左右手动结束收集并揭晓；不催促、不点名、不批评。不需要等满参考倒计时。没有答案也能继续。第四关零票时讲标注的假设角色故事，第六关零票时保留四个想法，会后继续征询，不虚构共同选择。

每项结果只代表有效参与者。主观题不限制字数，长弹幕可点开全文；分享可以不写。离线方案须提前下载，离线现场录入与云端手机答案分开。
