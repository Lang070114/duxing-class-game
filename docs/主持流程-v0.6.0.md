# 笃行班五关主持流程（v0.6.0）

45分钟班会：班长开场3分钟、团支书介绍4分钟、文娱委员介绍5分钟、游戏15分钟、院领导讲话15分钟、转场机动3分钟。游戏计时仅供提醒，不自动结束收集或跳关。

| 游戏时间参考 | 环节 | 操作 |
|---|---|---|
| 0—1分钟 | 扫码集合 | 新建正式房间，保存私密入口；独立投影页只展示给同学 |
| 1—3分钟 | 百歌回忆存档 | 开始收集、动态弹幕、结束、揭晓 |
| 3—5分钟 | 东校园生存指南 | 收集时弹幕，结束后卡片墙 |
| 5—7分钟 | 大二版本更新日志 | 状态单选、留言选填，揭晓后显示分布与词云 |
| 7—10分钟 | 24小时不够用 | 四方向选二，结束、揭晓真实分支与道具彩蛋 |
| 10—13分钟 | 我们班的大学第二季 | 六种电影类型单选，片名选填；审核片名、结束收集、揭晓 |
| 13—15分钟 | 报告与转场 | 保存报告PNG，进入院领导寄语页面 |

每关基本顺序：开始收集 → 结束收集 → 揭晓结果 → 下一关。电影终关揭晓前只显示整体提交人数，不显示分布；电影类型先揭晓，然后呈现最高票类型与对应结局，已审核片名另行展示。并列第一全部保留。最后点击“展示最终结局 / 通关报告”。

电影终关的片名无论内容如何，都先进入主持端的回答管理区；点击“审核通过并展示”后，也要等本关揭晓才出现在大屏。留空片名同样能提交投票。隐藏片名不会减掉电影类型的一票。若同学在开放收集期间修改已审核片名，需要重新审核。

可以点“上一关”返回，答案保留。需要补交时点击“重新开放收集”；未揭晓题及重新开放的题不显示分布。不要用“重置本场”返回，它会清空本场答案。

参与自愿：20秒后可以显示备用讲解，30秒左右手动结束等待，不必等满倒计时。零票时仍可继续，页面说明没有有效投票，不指定赢家；备用故事和演示数据均有明确标记。正式房间不能添加演示数据。

## 电影终关串词

“如果把我们班目前的大学第二季拍成一部电影，你觉得它最像哪一种？选一个就行，愿意的话，也可以给它起个名字。”

只描述参与者的选择，不把少数票说成全班意见。公开片名可以保留吐槽与幽默，不要求同学解释个人选择。

## 转场

“刚才大家给我们班的大学第二季选了不同的电影类型，也起了不少有意思的名字。看来，虽然我们在同一个班，但每个人的大学生活还是有自己的样子。”

“接下来，我们也非常荣幸邀请学院领导，结合大家的学习生活和成长需求，为我们新学年的大学生活分享一些建议。”

如果没有片名，省去“也起了不少有意思的名字”，自然转到每个人有自己的感受。

## 保存与备用

保存私密入口可以恢复房间；导出PNG、HTML与CSV/完整备份可以保留结果。房间有七天有效期，请及时导出。旧房间继续原题义；升级后请用原主持口令新建房间体验五关。

提前下载断网应急HTML并存到主持电脑。全场断网时打开它，由主持录入现场自愿举手的真实人数与票数；片名由主持确认后录入。离线记录与云端记录分开，不混算。个别手机断网会提示重连；尚未收到成功提示的答案需重新提交。
