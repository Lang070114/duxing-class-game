# 笃行班 v0.5.0：第二轮真人反馈改进

这次更新先修改本地项目，通过检查后保存到同一个 GitHub 仓库，发布标签为 `v0.5.0-live-feedback`。腾讯云需要上传本次升级包并运行升级脚本才会更新；GitHub 推送不会自动修改腾讯云。正式使用的主持网址始终是 http://43.139.189.171/?view=host ，不需要每次登录云控制台。

## 检查结果与保留范围

保留 React/Vinext、共享 API、Node.js 24 + SQLite、匿名凭证、主持/投影/学生三端、轮询重连、手动推进、上一关、数据导出、演示房间和 Nginx + systemd 部署。修复原接口在揭晓前返回完整票数、页面直接渲染图表、词云机械删除否定词的问题。原先只有报告 HTML/PDF，缺少实际 PNG 导出和系统化的低参与方案。

## 本轮变化

| 项目 | 现在的行为 |
|---|---|
| 所有投票延迟揭晓 | 服务端保存逐题揭晓标记。准备、收集、暂停、结束收集期间，各角色接口都不返回该题汇总票数或提交人数，页面不渲染结果。只在主持人点击“揭晓结果”后显示真实人数、票数和比例。重新开放或再次向前进入该题时重新隐藏，答案保留。 |
| 防止提前报告泄露 | 进入报告、提前收尾、返回上一关都不等于揭晓。报告 HTML/PNG 共用一个数据模型，未揭晓的投票只显示说明。旧历史数据没有可靠揭晓记录的部分保守隐藏，不推断已揭晓。 |
| 词云语义 | 本地名词/感受词词表、分词与语义规则结合；先保护否定短语和双重否定，再处理其余文字。“不确定”“没方向”“不想社交”“不焦虑”“不是不喜欢”保留完整表达，与相反表达分开。程度词不单独入云。来源可回看，隐藏回答排除。 |
| PNG 导出 | Canvas 在本机绘制中文、关键词云、已揭晓统计图、校园推荐、公开原话与候选说明。每页 2000×2800；长报告自动分页，多个 PNG 打包为单个 ZIP 下载，不截断原话，也不上传外部服务。HTML/PDF 仍可用。 |
| 文案与演示 | 示例改为口语、具体小事，只出现在明确标注的演示房间或备用讲解里。正式房间拒绝注入模拟数据；备用内容不写入答案和计票。 |
| 无人/少人参与 | 每关提供独立备用讲解，第四关有明确标注的假设角色故事。主持可一键显示；零票不排名，少量票标明人数与参考性质。20秒后提示可讲备用内容，30秒左右手动结束等待；没有自动关题或跳关。 |
| 第三关 | 状态选择优先，文字选填，可以整题跳过。弹幕收集，揭晓后显示状态与词云。 |
| 第五关 | 新房间采用“寻找班级搭子”：干饭、运动、学习、兴趣、游戏、散步聊天，可多选、留言选填。不收集联系方式、不公布个人类别、不自动配对；会后在班群自愿邀请。 |
| 第六关 | 新房间从干饭情报局、兴趣搭子计划、百歌隐藏相册、活动盲盒四项中各选两项，统计得票较高的候选；第二名并列保留。反复说明仍需确认可行性、负责人、时间，不构成现场承诺。 |
| 长回答与隐私 | 无逐题字数上限；手机多行输入随内容增高，过长后可滚动。弹幕显示明确标注的预览，可点开完整原话；报告网页折叠长文，导出保留全文。明显手机号/邮箱/身份信息与部分攻击性词句暂存待主持确认，原文完整保留；其他文字直接展示，可事后隐藏。 |
| 百歌照片 | 主持可选择最多6张已获授权照片，保存在本机浏览器，同一浏览器的投影页同步。不上传服务器，不作为实时投稿，不进入统计或报告，可随时移除。 |

## 腾讯云升级：只做一次

1. 在 OrcaTerm 文件管理器中把 `duxing-game-v0.5.0.zip` 上传到 `/root`。
2. 复制执行：

```bash
unzip -n /root/duxing-game-v0.5.0.zip -d /root/duxing-update-v0.5.0
bash /root/duxing-update-v0.5.0/update-tencent.sh
```

脚本先停止服务并备份代码、数据库、主持口令和 Nginx 配置，再升级并检查 HTTP；失败自动恢复。不会修改原主持口令。备份在 `/opt/duxing-backups/日期时间-v0.5.0`，请勿公开。

3. 看到“升级完成：游戏 v0.5.0”后，电脑 Ctrl+F5；手机关闭旧页面后重新扫码。
4. **这次第五、六关题义改变，正式班会请用原主持口令新建一个房间。** 原房间和答案保留原题义，可继续找回；旧超能力/设施投票不会被改解释为搭子/彩蛋。保存新房间的“私密入口”和同学二维码。主网址与主持口令不变。

## 本地启动与多人测试

已安装依赖时，在项目目录执行：

```text
npm run build:standalone
npm run start:standalone
```

打开启动窗口给出的主持地址。需要 Node.js 24；首次安装依赖用 `npm ci`。本机测试时的主持口令位于 `standalone-dist/data/host-key.txt`，与腾讯云数据目录分开。正式班会只用云端地址，避免混淆。

主持创建“演示房间”，另开投影页，手机扫描该房间二维码。也可用不同浏览器模拟不同同学（同一浏览器共享匿名凭证）。手机不能访问电脑的 `127.0.0.1`；局域网测试用启动窗口给出的电脑局域网地址，手机和电脑连同一 Wi-Fi，并确认网络允许互通。不要把私密主持链接发给同学。

关键验收顺序：开始收集 → 提交 → 结束收集（无票数）→ 揭晓（真票数）→ 上一关/重新开放（答案保留、统计隐藏）→ 报告图片下载。投票可以全程零人提交，主持仍能走完六关。演示与正式数据隔离。

## 实际验证与限制

257项自动化检查覆盖 40 个并发模拟参与者、六关共240份回答；零/1/2人完整流程；提交截止、编辑去重、暂停、参考计时到点不跳关、上一关、重开、提前报告、三端权限、旧数据库迁移、隐私暂存、隐藏、演示隔离、否定词与程度词边界。测试结果写入发行包 `version.json`。

浏览器已实际验证长中文提交、二选投票、揭晓前后页面、词云来源、390像素手机布局、服务停止时保留草稿并禁用提交、恢复后成功保存、自包含应急页在服务停止后走完六关，以及实际下载并逐页查看 PNG。测试报告包含约两千字的长留言，先后导出6页与7页2000×2800 PNG，中文、词云、图表与跨页内容可读。

已通过 TypeScript、独立运行构建及原 Vinext 构建。未代替现场真实微信/教室网络测试，也尚未在腾讯云安装本次更新。开会前需安装升级包、用真实手机扫新房间二维码、确认主持口令和私密入口、下载离线文件，并核对云服务器有效期覆盖10月30日。

语义和内容过滤为可维护的本地规则，不能理解所有反讽、复杂指代或隐私变体；发现不合适内容仍需主持隐藏。未提供或核实真实店铺清单，因此备用页提供实用选餐提示，不伪造商家推荐。照片需由班委确认授权并自行选择。离线版不接收手机答案、不自动同步云端；现场手动录入另行标注，不与云端混算。单次请求仍有1MiB传输保护，不是逐题字数限制。建议在电脑端导出长报告。

## 主要文件

`app/game-client.tsx` 与 `app/game.css`：三端流程、延迟结果、长文字与报告界面；`app/photo-memory.tsx`：仅本机照片；`app/api/game/route.ts`：真实聚合、揭晓权限、备用状态、过滤暂存；`lib/game.ts`：玩法与兼容题义；`lib/wordcloud.ts`：语义提取；`lib/report-image.ts`：网页/HTML/PNG共用报告模型及本机图片生成；`lib/fallback.ts`、`lib/content-safety.ts`：备用与基础过滤；`drizzle/0002_reveal_history.sql`：增量迁移；`standalone/offline-v5.ts`：离线应急；`scripts/test-game.mjs`：回归测试。原运行服务与部署目录保持不变。
