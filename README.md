# 笃行班：我们班，正在联机！

2026年10月30日班会互动游戏。约28人同时参与，包含手机匿名答题、独立主持台、投影页和持久数据库。

## 使用

- 同学入口：网站首页，输入房间码；或微信扫描主持页生成的二维码。
- 主持入口：`/?view=host`，使用私密口令创建房间。
- 时间仅作参考：倒计时不会自动关题、跳转或生成报告，所有推进由主持人决定。
- [主持流程与剧情](docs/主持流程.md)
- 断网前下载 `public/offline.html`，本地打开后用举手、口头分享及现场录入继续。

## 开发

Node.js >=22.13。运行 `npm ci` 安装依赖；`npm run dev` 启动本地预览。复制 `.env.example` 中的变量名到未跟踪的 `.dev.vars` 并填写自己的主持口令。

数据库迁移位于 `drizzle/`，需要按顺序应用。Sites发布时应用线上迁移；本地迁移见 `docs/开发与恢复.md`。

## 验证与版本

`npx tsc --noEmit`；`npm run build`；启动本地预览后运行 `node scripts/test-game.mjs`，测试仅允许连接本机，模拟40人同时参与，验证保存、更新去重、隐藏、权限和主持手动推进。

每个可运行版本保存为Git提交，并在发布阶段设置版本标签。恢复代码不会自动恢复数据库，也不会自动改变线上发布版本。

## 数据

答题以随机匿名凭证关联，不收姓名学号。开放文字直接展示，主持人可事后隐藏。CSV/JSON完整导出由主持权限保护。数据库、密钥、主持链接、实际答题记录均不进入GitHub仓库。

房间从创建起7天后停止访问；清理任务删除已到期房间及关联答题。需长期留存时在到期前导出。以实际发布交付说明记录清理任务是否配置成功。

## 架构

React + Vinext；Sites托管服务端；Cloudflare D1；同源HTTP API每2秒同步，页面在后台时降低频率。二维码由本地组件生成，不调用第三方二维码图片服务。主持与投影使用不同权限凭证。
